# Проверки CSV Cleaner

Из корня проекта: `npm test`, Node.js 24+. Набор содержит 27 тестов через встроенный node:test. Установка пакетов не нужна.

| Уровень | Что проверяется |
| --- | --- |
| CSV | BOM, кавычки и удвоенные кавычки, CRLF/LF, переносы и разделители внутри значений, пустые ячейки, ошибки структуры |
| Очистка | Порядок правил, дубликаты, пустые записи, сохранение строковых значений и ведущих нулей, полный экспорт |
| Рабочее состояние | Автоопределение/неоднозначность, раздельные разделители импорта и скачивания, ошибка импорта, привязка изменений к исходным записям |
| HTTP | Разрешённые ресурсы, MIME, CSP, HEAD, запрет POST и доступа к внутренним файлам |

## Браузерная приёмка — 22 октября 2026

В Chromium на Windows проверены пример 7 → 4 строки, отмена правил, сравнение исходника/результата, импорт UTF-8 BOM с точкой с запятой, кавычками и внутренним CRLF. Смена разделителя скачивания не меняет данные. Скачанный файл отдельно разобран и сопоставлен с ожидаемыми значениями.

Проверены незакрытые кавычки, неоднозначный CSV, пустой файл, только заголовки, неподдерживаемая кодировка и превышение 5 МиБ. Ошибочный разбор блокирует экспорт; отклонение файла до чтения сохраняет предыдущую рабочую таблицу.

Предпросмотр 100 × 30 проверен на файле 105 × 31: скачивание содержит все значения. Проверены Tab, стрелки/Home/End на вкладках, ширины 320, 390, 768 и 1440 px; горизонтальная прокрутка широкой таблицы остаётся внутри контейнера.

## Что не подтверждено

Firefox, Safari и физические мобильные устройства не проверены. Набор синтетических файлов не заменяет исследование реальных выгрузок. Работы по UX и устойчивости перечислены в [BACKLOG.md](BACKLOG.md).

GitHub Actions выполняет npm test на Node.js 24 в Ubuntu и Windows. Браузерная приёмка выполняется отдельно; workflow не устанавливает браузер и не имитирует её выполнение.
